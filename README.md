# SmartWasteSystem
The SmartWaste System collects information about waste bins, vehicles, and road networks and stores it in a central database. The Bin Priority Module identifies bins that need urgent collection based on fill level, filling rate, and overflow risk. The system then allocates suitable vehicles and calculates the shortest or least-cost route. If bin status, vehicle availability, or road conditions change, the system dynamically re-optimizes the route. Finally, the system simulates and evaluates the collection process using parameters such as distance, collection time, number of bins collected, vehicle utilization, and overflow risk, and presents the results through the user interface.
